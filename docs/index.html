Como instalar no Android

  1. Toque em Baixar para Android. O navegador vai avisar que o arquivo pode ser prejudicial — é o aviso padrão para apps que não vêm da Play Store. Toque em Baixar mesmo assim.
  2. Abra o arquivo baixado. O Android vai pedir permissão para instalar apps desconhecidos. Autorize para o navegador que você usou.
  3. Toque em Instalar e depois em Abrir.
  4. Digite o código de acesso na primeira tela.
Quando sair uma versão nova, o próprio app avisa e traz você de volta a esta página. Instale por cima: a rotina, as estrelas e as figurinhas são preservadas.
